# Continuous Research Page

The application uses one scrollable research story instead of isolated dashboard tabs. A fixed left-hand table of contents provides direct access to each evidence layer.

```text
┌──────────────────────┬─────────────────────────────────────────────┐
│ Research contents    │ Meme Signal Lab                             │
│                      │ social intelligence workspace               │
│ 0. CA workflow       ├─────────────────────────────────────────────┤
│ 1. Current finding   │ Reusable CA entry (public read-only)        │
│ 2. Participants      │ [contract address] [chain] [window]         │
│ 3. Language signals  ├─────────────────────────────────────────────┤
│ 4. Lifecycle         │ AX1  ○     NIULAI  ○                        │
│ 5. Market alignment  ├─────────────────────────────────────────────┤
│ 6. Risk evidence     │ Current finding                             │
│ 7. Calibration       │ Key sentence + five decision metrics        │
│ 8. Methodology       │ Topic keywords                              │
│                      ├─────────────────────────────────────────────┤
│                      │ Participant groups                          │
│                      │ Topic / stance / speech-act analysis        │
│                      │ Lifecycle and social-market timeline        │
│                      │ On-chain and execution risk gaps            │
│                      │ Benchmark and source methodology            │
└──────────────────────┴─────────────────────────────────────────────┘
```

## Information hierarchy

1. **Conclusion first:** a non-technical visitor should understand the current finding without reading the tables.
2. **Evidence next:** metrics, topics and participant types explain the finding.
3. **Sequence before causality:** social and market changes share a time axis but are not described as causal.
4. **Risk before action:** missing contract, holder and execution evidence is visible before raw posts.
5. **Audit last:** source links, query boundaries and raw records remain available without overwhelming the first screen.

## Interaction rules

- AX1 and NIULAI never share a selected-case panel.
- Every timestamp shown to users is Asia/Shanghai; stored event time remains UTC.
- A label must be understandable without domain shorthand or include a short explanation.
- The public CA field demonstrates reusability, while paid collection controls remain inside the administrator panel.
- The interface reports evidence and uncertainty, not buy or sell instructions.

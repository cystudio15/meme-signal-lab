# Meme 社媒信号指标树

## 目标

帮助用户更早、更可靠地理解 Meme 信号，减少把曝光误当机会、把热度误当安全。

本指标树严格分开四件事：

1. **热度**：注意力和交易活动有多强。
2. **真实性**：活动是否来自广泛、独立且有信息量的参与。
3. **传播阶段**：社媒领先市场，还是价格上涨后才出现拥挤讨论。
4. **可交易性**：流动性、滑点、合约和持仓风险是否允许执行。

热度高不等于值得买，也不等于产品应当高置信推送。

## OSM

| OSM | 产品场景 |
|---|---|
| Objective | 提高用户识别有效 Meme 信号的效率与可信度 |
| Strategy | 社媒发现、来源验证、传播诊断、市场确认、风险检查、结果归因 |
| Measurement | 采集质量、社媒热度、传播真实性、市场热度、阶段、可交易性和用户结果 |

## 一级指标

### 1. 采集质量

- 原始读取量、唯一帖子数和重复率
- 查询轨覆盖范围
- 引用图新增召回率
- HTTP、分页、限速与失败状态
- 单次采集条数与请求上限

### 2. 社媒热度

- 5/15/60 分钟帖子增速
- 独立作者增速
- 原创、引用、转发和回复构成
- 加权互动量及其中位数、P90
- 引用传播深度和下游扩散速度

### 3. 传播真实性

- Top 作者贡献占比和来源集中度
- 单次出现作者比例
- 重复文案和低信息回复比例
- 官方、KOL、社区、推广和疑似自动传播构成
- 多语言、跨社群和跨地区扩散

### 4. 交易热度

- 5/15/60 分钟成交笔数增速
- 成交量增速
- 独立交易者与新钱包增速
- 买入/卖出方向
- 成交量/流动性周转率

### 5. 传播阶段

- 首次社媒讨论 → 首次扩散 → 交易放大 → 价格反应的时间差
- 社媒和交易是否同步确认
- 价格是否已在讨论爆发前显著上涨
- 热度仍在但买入、流动性或钱包质量是否转弱

### 6. 可交易性与风险

- 流动性、预估滑点和池龄
- 合约权限、LP、持仓集中和 DEV 行为
- 证据来源冲突
- 最大有利波动、最大回撤和执行成本

## 当前原型与未接入指标边界

当前公开数据可以计算帖子、作者、传播关系、市场变化和风险代理指标。以下指标需要产品行为日志，作品只给定义，不声称已经测量：

- 信号展示 → 查看证据 → 收藏/监控 → 交易的漏斗
- 不同信号来源的安全交易转化
- D7/D30 用户留存
- 投诉、风险代币交易和长期用户结果

未来的北极星指标可定义为：

> 30 日内至少完成一次“查看证据并作出有效信号决策”的留存用户数。

在没有产品行为埋点前，不能把公开 X 互动冒充平台用户收益。

## AX1 当前结论

AX1 已观察到直接引用和下游扩散。市场侧从389个Base池中匹配40个最接近的池，AX1的24小时成交额、交易笔数、独立交易者和成交额/流动性均位于P97.5，因此可以说：

> 社媒传播已形成；采集时点的市场活跃度处于同阶段样本高位。

但跨币社媒真实性和历史结果基准仍未完成，所以不把市场百分位包装成上涨概率或综合投资分。
